# Package index

## All functions

- [`filter_by_arch()`](filter_by_arch.md) : Filter by arch if it has
  arch-specific and universal binaries

- [`get_arch()`](get_arch.md) : Get the arch

- [`get_binary_os()`](get_binary_os.md) : Get OS abbreviation

- [`get_candidates()`](get_candidates.md) : Get candidate packages in R
  Universe based on criteria

- [`get_jobs()`](get_jobs.md) : Get jobs for an R Universe build

- [`get_macosx_subpath()`](get_macosx_subpath.md) : Get macosx repo
  subpath by R version

- [`get_raw_uni_df()`](get_raw_uni_df.md) : Get packages in an R
  Universe

- [`get_repository_path()`](get_repository_path.md) : Get repo path

- [`get_uni_df()`](get_uni_df.md) :

  Flatten raw universe data.frame by matching R, OS, and arch
  information from `_jobs` with `_binaries`

- [`get_uni_for_bioc_version()`](get_uni_for_bioc_version.md) : Get
  information about R Universe building a Bioconductor version

- [`r_xy_ver()`](r_xy_ver.md) : Get x.y version of R given x.y.z

- [`remove_old_binaries()`](remove_old_binaries.md) : Remove old
  binaries if a new binary exists

- [`uni_pkg_file()`](uni_pkg_file.md) : Construct binary file name

- [`uni_repo_url()`](uni_repo_url.md) : Get universe URL for an os and R
  version
