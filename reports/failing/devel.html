469 packages fail in BBS or R Universe on x86_64-linux-gnu: 385 software, 63 experiment data, 14 workflows, 7 books. Sorted by downloads.

R Universe error Packages
Legend
  • BBS: the first stage that fails: install, build, or check, with ERROR or TIMEOUT. Links to the BBS log.
  • R Universe: the first job that fails: source build or check, with ERROR, FAIL, or TIMEOUT, or the overall status if only that failed. Links to the job.
  • R Universe error: the step that failed and the likely cause, found in the job’s log. Links to the log. Expand a row to see the first error lines. Causes:
    • Hub resource: an ExperimentHub or AnnotationHub download failed.
    • Network/web service: a download or web service failed.
    • Missing package: a package is not available, for example archived on CRAN.
    • Missing cached data: data the package expects in a cache was missing.
    • External tool: Python, Java, Conda, LaTeX, or a command line tool.
    • Dependency changed: a function or class the package uses changed or was removed.
    • Timeout: the job ran out of time.
    • Test expectation failed: a test’s result no longer matched.
    • Other: none of the above, often a bug in the package.
  • Downloads / month: distinct IPs downloading the package from Bioconductor in the last 12 months, divided by 12.
  • Strong reverse deps: Bioconductor packages that depend on, import, or link to the package. Expand a row to see them and the packages that suggest it.
  • Mentions (R Universe _mentions): mentions in scientific papers.
  • Commits (12 weeks) (R Universe _updates): commits in the last 12 weeks, a sign the maintainer is working on the package.
